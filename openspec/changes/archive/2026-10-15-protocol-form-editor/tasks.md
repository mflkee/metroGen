- [x] 3.4 Тесты: `steps_from_fractions`; генератор отдаёт ровно точки формы (3 и 5 строк) и не меньше 8 по умолчанию; извлечение точек и колонок из структуры.

### Решение по колонкам (было 3.5)

Заголовки таблиц во всех шаблонах — многорядовые (`colspan`/`rowspan`, например «Показания поверяемого СИ» над «прямой ход / обратный ход»). Перевести их в данные нельзя «между делом»: сначала нужно решить, как значения генератора маппятся на колонки (сейчас строки — это словарь с ключами вида `si_fwd`, `ref_fwd`, `var_pct`), иначе новая колонка окажется пустой. Поэтому в этом change структура управляет **точками замера**, а заголовки остаются в шаблонах; колонки из структуры уже уезжают в контекст (`table_columns`) и используются в предпросмотре. Data-driven колонки — отдельный change вместе с generic-рендерером.

## 4. API

- [x] 4.1 `PUT /api/v1/templates/{code}/draft` — черновик (структура и/или оверлей) с валидацией.
- [x] 4.2 `POST /api/v1/templates/{code}/publish` — публикация версии (комментарий, автор, время).
- [x] 4.3 `GET /api/v1/templates/{code}/versions` и `POST .../versions/{revision}/restore` (откат публикует новую версию, история не переписывается).
- [x] 4.4 `POST /api/v1/templates/{code}/preview` — предпросмотр черновика.
- [x] 4.5 Права: изменяющие ручки требуют `DEVELOPER`/`ADMINISTRATOR` (`AdminUser`); тест — `401` без токена.
