# Proposal

## Why

Конструктор форм умеет менять **точки замера**, но не колонки: заголовки остались в HTML-шаблонах
(многорядовые, `colspan`/`rowspan`), а значения строк — словарь генератора (`si_fwd`, `ref_fwd`,
`var_pct`). Поэтому «собрать табличку» получается наполовину: добавить колонку или переименовать её
нельзя, а открытый вопрос — как значения маппятся на колонки — блокирует весь сценарий.

Решаем вопрос явно и узко: колонка описывается парой **«заголовок + источник значения»**, и таблица
рендерится из структуры там, где форма уже управляет протоколом.

## What Changes

- **Колонка = заголовок + источник.** В структуре у колонки появляется поле `source` — ключ значения:
  сначала ищется в строке генератора (`si_fwd`), затем в контексте (`allowable_error`).
- **Generic-таблица из структуры.** Когда форма управляет протоколом (`renderer = "data"`) и в её
  структуре есть таблица, главная таблица протокола рендерится из структуры (один ряд заголовков,
  значения по `source`). Иначе — прежний HTML-шаблон: поведение по умолчанию не меняется.
- **Область — главная таблица.** Многотабличные формы уровнемера (вторая таблица, токовый выход)
  остаются в шаблоне: структура управляет первой таблицей.
- **Редактор**: у колонки можно править заголовок и источник; список источников подсказывается по
  ключам строк генератора для этой формы.
- **Предпросмотр** показывает таблицу с источниками (значения — при генерации).

## Capabilities

### New Capabilities

- `protocol-form-table`: как таблица протокола собирается из структуры формы — заголовки колонок и
  значения по источникам, и когда используется прежний HTML-шаблон.

### Modified Capabilities

- None (архивный `protocol-form-editor` описывает структуру и точки; здесь добавляется рендер таблицы).

## Impact

- **Backend**: `app/services/form_structure.py` (валидация `source`, предпросмотр),
  `app/services/form_structures.py` (сборка таблицы из структуры + строк генератора),
  `app/services/protocol_builder.py` (кладёт `structure_table` в контекст).
- **Шаблоны**: `app/templates/_structure_table.html` (новый include), `pressure.html`, `level_meter.html`
  — главная таблица обёрнута в `{% if structure_table %}`.
- **Frontend**: `StructureEditor` — поле «источник» у колонки; подсказка ключей.
- **Риск паритета**: путь по умолчанию (без структуры) не меняется; проверяется тестом.
